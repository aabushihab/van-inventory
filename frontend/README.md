# نظام المخازن والمبيعات وتحميل سيارات التوزيع — الواجهة الأمامية (Frontend)

واجهة أمامية مبنية بـ **React 19 + Vite + MUI**، ثنائية اللغة (عربي RTL / إنجليزي LTR) قابلة للتبديل الفوري
من زر اللغة أعلى الشاشة، وتتصل بالـ API الخلفي (Spring Boot).

## المتطلبات

- Node.js 20+
- تشغيل الباك-إند على `http://localhost:8090` (راجع مجلد `backend`)

## التشغيل محلياً

```bash
npm install
npm run dev
```

سيعمل على `http://localhost:5173` وتتم إعادة توجيه طلبات `/api` تلقائياً إلى `http://localhost:8090`
عبر إعداد الـ proxy في `vite.config.js` (لا حاجة لأي إعداد إضافي في وضع التطوير).

للإنتاج، انسخ `.env.example` إلى `.env` وحدد عنوان الـ API الفعلي:
```
VITE_API_BASE_URL=https://your-api-domain.com/api
```
ثم:
```bash
npm run build
```
سينتج مجلد `dist/` جاهز للنشر على أي خادم استضافة ثابت (Nginx, Netlify, Vercel...).

> تم التحقق من نجاح `npm run build` فعلياً أثناء إعداد هذا المشروع (بدون أخطاء).

## تسجيل الدخول الافتراضي

- اسم المستخدم: `admin`
- كلمة المرور: `Admin@123`

## الصفحات المتوفرة

- **لوحة التحكم**: ملخص المبيعات اليومية/الشهرية، عدد الفواتير، نقص المخزون، التنبيهات غير المقروءة.
- **المنتجات**: بحث، فلترة، إضافة/تعديل (الوحدة، عدد الحبات بالكرتونة، الأسعار، حد التنبيه).
- **سيارات التوزيع**: إضافة سيارة (رقم لوحة بصيغة `12-34567`)، ربط سائق ومندوب، عرض الحمولة، جرد السيارة وإرجاع المتبقي.
- **تحميل السيارات**: سندات تحميل/تنزيل متعددة الأصناف مع التحقق من الكميات، وإلغاء السند.
- **تسوية السيارات**: حركة كل صنف على السيارة (محمّل، مباع، مرتجع، منزّل، متبقي) مع المبيعات والتحصيل.
- **سيارتي** (للمندوب): حمولة سيارته الحالية وزر البيع منها — فاتورة المندوب مقيّدة بمخزن سيارته وبالكميات المتوفرة عليها.
- **التصنيفات والوحدات**: إدارة تصنيفات المنتجات ووحدات القياس.
- **الفروع والمخازن**: دعم عدة فروع وعدة مخازن لكل فرع.
- **المخزون**: عرض الأرصدة لكل مخزن، تعديل يدوي، نقل بين المخازن، سجل حركات المخزون الكامل.
- **فواتير الشراء / فواتير البيع**: إنشاء فاتورة متعددة الأصناف مع حساب تلقائي للضريبة والخصم والإجمالي،
  ثم طباعة A4 أو إيصال حراري (يفتح PDF في تبويب جديد جاهز للطباعة).
- **العملاء والموردين**، **المستخدمون**، **الأدوار والصلاحيات** (تحديد صلاحيات مخصصة لكل دور)،
  **التنبيهات** (تنبيهات نقصان المخزون).

## الصلاحيات في الواجهة

القوائم الجانبية والأزرار تظهر/تختفي تلقائياً حسب صلاحيات المستخدم المسجّل دخوله (المستلمة من الخلفية عند تسجيل
الدخول)، بحيث لا يرى المستخدم إلا ما يملك صلاحية الوصول إليه فعلياً.

## هيكل المشروع

```
src/
├── api/            عميل axios + دوال استدعاء كل وحدة API
├── context/        AuthContext (تسجيل الدخول، المستخدم الحالي، فحص الصلاحيات)
├── components/      Layout، ProtectedRoute، CrudPage (جدول CRUD عام قابل لإعادة الاستخدام)
├── pages/          كل صفحة من صفحات النظام
├── locales/        ملفات الترجمة (ar.json / en.json)
├── theme/          إعداد MUI + دعم الاتجاه RTL/LTR ديناميكياً
└── i18n.js         إعداد i18next
```
